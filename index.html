CH.02

One host, every tab, no arguing

Only the tab where you press ON captures the microphone — that's the Host. It calculates loudness locally, then broadcasts it through background.js, which relays the number to every other open tab. A single chrome.storage.local flag keeps every tab's toggle state honest, so nobody's confused about whether the chaos is currently live.

CH.03

Say the wrong right thing

A second, decoupled recognition loop listens for two phrases. It runs on its own thread from the 60fps meter, so catching a command never stutters the volume tracking. Say the trigger, and recognition.abort() fires before the real destination ever loads.

> listening

"Open Google" → intercepted, aborted, LinkedIn opens in a new tab instead.

"Open Wikipedia" / "Open wiki" → intercepted, aborted, Instagram opens in a new tab instead.

CH.04

The silence protocol

The moment RMS amplitude drops below the noise floor — about 0.025 — a ten-second countdown starts inside the same audio loop. Go quiet for the full ten, and every tab's media volume spikes to 100%, prank.mp3 plays, and the button itself turns on you.

SPEC

What's actually in the folder

No Chrome Web Store listing exists for this — a prank extension with a jumpscare and a fake reroute would get rejected on principle. It's a "load unpacked" project, built for people you like.

Files

  • manifest.json
  • background.js
  • content.js
  • spotify_bridge.js
  • prank.mp3

Permissions

  • "tabs" — relay volume across every open tab
  • "storage" — sync the ON/OFF state globally
  • web_accessible_resources: prank.mp3
  1. Download or clone the extension folder to your machine.
  2. Open chrome://extensions and turn on Developer mode.
  3. Click "Load unpacked" and select the folder.
  4. Open the extension, press ON in whichever tab you want as Host.
  5. Whisper. Yell. Go quiet and see who flinches first.
